Description:
A web application to manage car rentals. Customers can browse available cars, make reservations, and manage their bookings. Admins have the ability to confirm or refuse reservations. The application demonstrates full-stack development using Spring, MySQL, and front-end technologies.

Technologies Used:

Backend: Spring Boot, Spring MVC, Spring Data JPA

Database: MySQL

Frontend: HTML, CSS, JavaScript

Version Control: Git / GitHub

Features:

Customer registration and authentication

Browse available cars and view details

Make, update, or cancel reservations

Admin panel to manage bookings and confirm/refuse reservations

Responsive user interface for easy navigation
